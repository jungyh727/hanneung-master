# 한능검 마스터 — 아이폰 무료 설치 웹앱

## 목적
아이폰 Safari에서 '홈 화면에 추가'를 통해 설치 가능한 PWA입니다. **앱스토어 IPA 앱은 아닙니다.** 서버 비용 없이 GitHub Pages 등에 정적 웹사이트로 배포합니다.

## 설치 및 공유 (GitHub Pages 무료)
1. GitHub 계정을 만듭니다.
2. 새 **Public** 저장소를 만들고 이 폴더 내 파일(`index.html`, `app.js`, `bank.json`, `manifest.webmanifest`, `sw.js`, 두 PNG)을 저장소 최상위에 업로드합니다.
3. 저장소 **Settings → Pages → Build and deployment → Deploy from a branch → main /(root) → Save**를 선택합니다.
4. GitHub Pages에서 제공하는 `https://계정.github.io/저장소/` 주소를 여자친구에게 전송합니다.
5. **아이폰 Safari**에서 해당 주소를 열고 **공유 → 홈 화면에 추가**를 누릅니다. 홈 화면의 아이콘으로 실행합니다.

## PDF → 문제은행
- 자료실 → PDF 업로드에서 요약노트 PDF를 넣으면 PDF.js를 통해 텍스트를 추출합니다. 인물·대상과 서술 사실이 파악되는 경우 후보로 나옵니다. 사실이 잘못 인식될 수 있으니 반드시 '검토 후 등록'해야 합니다. 자동 인식에 실패할 수 있습니다.
- 텍스트 내 '주제: 사실' 또는 `시대|시기|분야|인물·대상|실제 역사적 사실` 형식이 가장 정확합니다.
- 기출 PDF: ①~⑤ 선지가 포함된 텍스트형 PDF에서 문항 추출을 시도합니다. 정답표에 있는 정답 번호를 **문항 순서대로 사용자가 입력**해야 합니다. 검토 화면에서 문항과 배점을 수정해 등록해야 합니다. 복잡한 다단 형식, 이미지형 스캔 PDF는 인식하지 못할 수 있습니다.
- **기출 문제의 자동 정답 판별이나 AI 자동 문제 생성은 구현되지 않았습니다.** 추출된 사실을 이용한 관계형 문제는 자동 구성됩니다. 역사적 사실이 아닌 허위 진술을 선지로 만들지 않습니다.

## 학습 기록·개인정보
- 학습기록, 오답노트, PDF에서 **추출해 저장한 사실과 문항**은 각 기기의 IndexedDB에 저장됩니다.
- PDF 원본 파일 자체는 서버에 전송하지 않으며 저장되지 않습니다. PDF.js 라이브러리는 최초 사용 시 공개 CDN에서 다운로드됩니다.
- 계정 가입·기기간 동기화 **미지원**. 둘은 같은 배포 주소를 사용해도 서로의 기록이 보이지 않습니다.
- iOS Safari/홈 화면 웹앱 데이터를 지우거나 휴대전화 교체 시 기록이 소실될 수 있으므로 자료실 → 백업 기능을 이용하세요.
- GitHub Pages의 **Public 저장소에 개인 자료를 직접 업로드하지 마세요.** PDF 등록은 앱 화면에서만 수행하세요.

## 채점
- 정확한 회차/문항/정답/배점이 완성된 50문항·100점 기출만 공식 배점에 따른 점수로 간주합니다.
- 그 외 모의고사, 부분 시험은 100점 환산점수 및 참고 급수를 표시합니다.

## 로컬 개발
`python -m http.server 8000` 실행 후 `http://localhost:8000` 접속 (PWA 설치 기능은 HTTPS 배포 후 사용).
